# Medical Website Prototype

An early front-end prototype for a medical-themed website, including a login screen and a basic path into the main experience.

## Why it matters

The repository explores the first layer of a healthcare interface: visual design, navigation, and user interaction.

## Technology

HTML, CSS, JavaScript, and GitHub Pages.

## View

[Open the live prototype](https://harsha3358.github.io/medical/)

To run locally, clone the repository and open `index.html`.

## Important limitation

The login is browser-side demonstration code and is not secure authentication. A real healthcare application would require a protected backend, encrypted data, access controls, audit logs, and privacy compliance.
